# @xshawalx UGC Portfolio

Official portfolio for Shawal (@xshawalx), a Kuala Lumpur-based Malaysian UGC creator.

## Stack
Plain HTML + CSS + JavaScript, designed for GitHub Pages. No framework or paid dependency is required.

## Updating portfolio work
Edit only `portfolio.js`. Add the social URL, title, categories, category label and content type. Instagram post/reel embed details are detected automatically; full TikTok `/video/ID` URLs can also embed automatically. Full TikTok `/video/ID` URLs embed automatically in the portfolio viewer. If a platform blocks an embed, each player also includes a direct “View on Instagram/TikTok” fallback link.
